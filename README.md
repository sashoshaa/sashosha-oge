# sashosha.math — ОГЭ 1–19 + кабинеты

Это статический сайт для GitHub Pages и дополнительный облачный модуль для групп, учеников и назначенных вариантов. Сам тренажёр (293 прототипа, из них 6 помечены OLD) работает без базы. Облачные кабинеты начнут работать **только после настройки Supabase** — без неё авторизации и синхронизации нет.

## Что есть

- Тренировка по номерам 1–19 и прототипам; случайный самостоятельный вариант из 19 заданий.
- Практическая пятёрка №1–5 из одного сюжета, с полным общим условием/планом на каждой карточке.
- Исправленные изображения общих условий всех восьми сюжетов и графиков №11 с новыми именами файлов (для обновления кеша).
- Преподаватель: вход по email, создание нескольких групп, коды приглашения, список учеников, назначение **разных случайных вариантов** всем или выбранным, результаты 0–19 и разбивка по номерам.
- Ученик: вход по коду группы и псевдониму без email на одном устройстве, список назначенных работ, заполнение, автосохранение черновика в облаке, сдача и просмотр результата.

## Сначала — обычный сайт

Распакуй архив в корень репозитория (рядом должны лежать `index.html`, `data.js`, `app.js`, `style.css`, `config.js`, `cloud.js`, `assets/` и `supabase.sql`).

В GitHub открой **Settings → Pages → Deploy from a branch → main → / (root)**. GitHub Pages предоставляет публичный сайт. Если доступ должен быть *строго* только ученикам, **GitHub Pages не ограничивает просмотр статических материалов**. Личные результаты защищаются отдельно политиками Supabase.

## Подключить настоящие кабинеты

1. Создай проект в [Supabase](https://supabase.com/). В SQL Editor проекта выполни **весь** файл `supabase.sql` одним запуском. Он создаёт таблицы, политики доступа, серверную проверку и загружает ключи ответов 293 прототипов.
2. В **Authentication → Providers** включи **Anonymous sign-ins**, чтобы ученики могли входить без почты. Проверь, что **Email** включён для преподавателя. В **Authentication → URL Configuration** укажи опубликованный URL сайта в `Site URL` и добавь его в `Redirect URLs` (например `https://sashoshaa.github.io/sashosha-oge/`). В интерфейсе Supabase названия настроек иногда меняются.
3. В **Project Settings → API Keys** (или **Connect → API keys**) найди **Project URL** и **publishable / anon key**. Впиши эти **публичные** значения в `config.js`. **Никогда не размещай `service_role`/secret key!**
4. Опубликуй обновлённый `config.js` в GitHub вместе со всем сайтом. Открой страницу, прокрути до раздела **«личный кабинет»**, войди по email и создай группу.
5. Отправь ученикам код из кабинета преподавателя. Ученики вводят код + псевдоним, после чего появляются в списке. Отметь нужных и нажми **«назначить выбранным»**.
6. Ученики открывают свою работу в кабинете. После сдачи в твоей таблице появится результат. Можно нажать **«по номерам»**, чтобы увидеть, какие задания решены верно.

## Ограничения и безопасность

- Без настроенного Supabase раздел кабинетов показывает честную инструкцию, а не имитацию работающих аккаунтов.
- Анонимный кабинет ученика зависит от сохранённой сессии в браузере. Если очистить данные браузера или сменить устройство, прежний кабинет **без email нельзя восстановить автоматически**. Для работы на нескольких устройствах потребуется добавить полноценный вход ученика через Supabase Auth. Это следующий шаг разработки.
- Не проси учеников указывать настоящие имена: можно использовать псевдонимы (`ученик 01` и т. п.). Учительский email нужен для входа преподавателя.
- Назначение и результаты хранятся в базе; доступ к данным разделён по идентификаторам пользователей и преподавателю их группы (Postgres RLS + контролируемые RPC).
- Проверка назначенных вариантов выполняется на сервере. Но ответы обычного самостоятельного тренажёра уже есть в общедоступном JavaScript, так что **это учебная платформа, а не защищённая экзаменационная система**.
- Варианты создаются из 287 активных прототипов. `OLD` и `SIM` не входят в рандомную сборку. Первая пятёрка относится к одному общему сюжету.
- Проект не собирает платежи и не включает рекламу.

## Структура

- `index.html`, `style.css` — интерфейс в стиле sashosha math
- `app.js`, `data.js` — самостоятельная тренировка и варианты
- `config.js` — **публичные** параметры подключения Supabase
- `cloud.js` — кабинеты, группы, назначение, синхронизация
- `supabase.sql` — база, ключи, права и функции
- `assets/*.webp` — картинки прототипов и полные общие условия

## Почта преподавателя

Supabase по умолчанию ограничивает отправку писем адресами команды проекта. Для первой проверки используй email, на который зарегистрирован Supabase. Для полноценного запуска может потребоваться настроить собственный SMTP (Authentication → SMTP Settings); иначе вход по ссылке может не приходить другим адресатам.
