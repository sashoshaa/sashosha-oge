# sashosha.math — тренажёр ОГЭ №1–19

Готовый статический сайт для бесплатных занятий с учениками. Работает без сервера и аккаунтов: HTML, CSS, JavaScript и изображения заданий.

## Что есть

- 293 прототипа по номерам 1–19; 6 архивных прототипов OLD скрыты по умолчанию.
- Проверка ответов, поиск по прототипам и статистика прогресса.
- Сборка случайного варианта из 19 задач: №1–5 из одного сюжета, №6–19 случайные.
- Адаптивный дизайн; увеличение изображений заданий.
- Результаты сохраняются только в браузере ученика (`localStorage`). Они не передаются преподавателю автоматически.

## Как разместить на GitHub Pages

1. Создайте репозиторий в GitHub (например, `oge-trainer`).
2. Загрузите **содержимое архива в корень репозитория**: `index.html`, `app.js`, `data.js`, `style.css`, папку `assets` и файл `.nojekyll`.
3. Откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните.
4. После публикации сайт обычно будет доступен по адресу вида `https://ВАШ-ЛОГИН.github.io/oge-trainer/`.

> Важно: даже если вы отправите ссылку только ученикам, обычный GitHub Pages не ограничивает доступ кругом учеников. Учитывайте это при публикации. Не размещайте личные данные учеников. Использование материалов — в рамках полученного вами разрешения на бесплатные образовательные занятия.

## Как открыть без GitHub

Распакуйте архив и откройте `index.html` в браузере. Все файлы должны остаться в той же структуре.

## Что пока не входит

- Тысячи аналогов с другими числами не перенесены: включены прототипы.
- Изображения условий представлены как фрагменты исходного материала, а не как вновь нарисованные SVG.

## Состав

- `index.html` — интерфейс;
- `style.css` — оформление;
- `app.js` — интерактивность и проверка;
- `data.js` — данные о прототипах и ответы;
- `assets/` — изображения условий;
- `.nojekyll` — файл совместимости с GitHub Pages.
